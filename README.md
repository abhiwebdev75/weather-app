🌤️ Skycast – A sleek and responsive weather app built with HTML, CSS, JavaScript, Tailwind CSS, and weather APIs.
Skycast delivers real-time weather updates, hourly forecasts, and location-based insights with a clean and modern UI.

✨ Features

🌍 Real-time weather data using public APIs

📍 Location-based weather detection

🔍 Search weather by city or region

⏱️ Hourly and 7-day forecast

🎨 Responsive and minimal UI with Tailwind CSS

🚀 Tech Stack

Frontend: HTML, CSS, JavaScript

Styling: Tailwind CSS

APIs: Weather API (OpenWeatherMap or similar)
